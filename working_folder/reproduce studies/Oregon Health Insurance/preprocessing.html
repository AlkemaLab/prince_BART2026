Oregon health insurance: preprocessing

Data preparation

Join the supplied descriptive and state-program records by person_id. The code saves only dat in processed_data.rda for Analysis.qmd. The raw ICPSR files remain in data/.

Code 
suppressPackageStartupMessages({
  library(haven)
  library(dplyr)
})

dat <- local({
  descriptive <- read_dta("data/ICPSR_34314/DS0001/34314-0001-Data.dta")
  programs <- read_dta("data/ICPSR_34314/DS0002/34314-0002-Data.dta")
  stopifnot(!anyDuplicated(descriptive$person_id),
            !anyDuplicated(programs$person_id),
            setequal(descriptive$person_id, programs$person_id),
            all(is.na(descriptive$numhh_list)))

  out <- descriptive |>
    transmute(
      person_id = as.integer(person_id),
      household_id = as.integer(household_id),
      postn_death = as.integer(postn_death),
      treatment = as.integer(treatment),
      draw_lottery = factor(as.integer(draw_lottery)),
      have_phone_list = as.integer(have_phone_list),
      pobox_list = as.integer(pobox_list),
      self_list = as.integer(self_list),
      week_list = factor(as.integer(week_list))
    ) |>
    left_join(
      transmute(programs, person_id = as.integer(person_id),
                ohp_all_ever_matchn_30sep2009 = as.integer(ohp_all_ever_matchn_30sep2009)),
      by = "person_id"
    )
  stopifnot(nrow(out) == 74922L, !anyNA(out),
            all(out$postn_death %in% 0:1), all(out$ohp_all_ever_matchn_30sep2009 %in% 0:1), all(out$treatment %in% 0:1))
  out
})
save(dat, file = "processed_data.rda", compress = "xz")

Variables and availability

Missingness is measured across all 74,922 people before any analysis exclusions. numhh_list is restricted and excluded from the saved model data. Household identifiers remain available for clustering; counting retained people does not recover the original lottery-list household size.
