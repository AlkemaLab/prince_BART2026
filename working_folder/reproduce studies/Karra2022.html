Study overview

Karra et al. (2022) randomized 2,143 women in Malawi to improved family planning access or control. The package provided counseling, transport, contraceptive services, and side-effect care. Adjusted intention-to-treat (ITT) analyses found a 5.9 percentage point increase in contraceptive use and a 3.7 percentage point reduction in subsequent pregnancy. Here, assignment instruments endline contraceptive use. Principal stratification targets the pregnancy effect among women whose use responds to assignment. This is an exploratory extension, since endline use may follow pregnancy and may not capture all pathways through which the package affects fertility.

Objective 1: Pregnancy among contraceptive-use compliers

First reproduce the authors’ adjusted pregnancy ITT model using its available cases. Then restrict dat to the common complete cases for 2SLS and princeBART.

Reproduce result

Follow DO_3_MAIN_RESULTS.do: adjust for baseline pregnancy and covariates, plus months since the index birth (exposure). Report an HC1 robust 95% CI.

fit_itt <- lm(
  Y ~ Z + exposure + preg_bl + area_bl + age_group_bl + sex_age_bl +
    total_alive_bl + ever_use_bl + edu_primary_bl + work_bl + religion_r_bl + ethnicity_r_bl,
  data = dat, na.action = na.omit
)
itt_estimate <- unname(coef(fit_itt)["Z"])
itt_se <- sqrt(vcovHC(fit_itt, type = "HC1")["Z", "Z"])
itt_result <- c(itt_estimate,
                itt_estimate + qt(c(0.025, 0.975), df.residual(fit_itt)) * itt_se)

2SLS analysis

Estimate the use coefficient with an HC1 robust, normal-approximation 95% CI.

# Exposure is used only in the ITT replication; the IV models use baseline X.
dat <- dat |>
  select(-exposure) |>
  filter(if_all(everything(), ~ !is.na(.x))) |>
  droplevels()

fit_iv <- ivreg(
  Y ~ W + curr_use_inj_adj_bl + preg_bl + area_bl + age_group_bl + sex_age_bl +
    total_alive_bl + ever_use_bl + edu_primary_bl + work_bl + religion_r_bl + ethnicity_r_bl |
    Z + curr_use_inj_adj_bl + preg_bl + area_bl + age_group_bl + sex_age_bl +
    total_alive_bl + ever_use_bl + edu_primary_bl + work_bl + religion_r_bl + ethnicity_r_bl,
  data = dat
)
iv_estimate <- unname(coef(fit_iv)["W"])
iv_se <- sqrt(vcovHC(fit_iv, type = "HC1")["W", "W"])
iv_result <- c(iv_estimate, iv_estimate + qnorm(c(0.025, 0.975)) * iv_se)

princeBART approach

Report the mixed complier effect: posterior mean and 95% equal-tail credible interval.

plan(multisession, workers = 4)
set.seed(123)
fit_ps <- prince_BART(
  Y ~ curr_use_inj_adj_bl + preg_bl + area_bl + age_group_bl + sex_age_bl +
    total_alive_bl + ever_use_bl + edu_primary_bl + work_bl + religion_r_bl + ethnicity_r_bl |
    Z | W,
  data = dat, uptake_type = "binary",
  n_chains = 4, n_warmup = 1000, n_samples = 2000,
  workers = 4, keep_trees = FALSE
)

tau <- unlist(lapply(fit_ps$chains, function(chain) {
  p_c <- 1 - chain$p_a - chain$p_n
  rowSums(p_c * (chain$m_y1c - chain$m_y0c)) / rowSums(p_c)
}), use.names = FALSE)
bart_result <- c(mean(tau), quantile(tau, c(0.025, 0.975), names = FALSE))

The published ITT concerns assignment, whereas the new estimates concern use among compliers; their samples and estimands differ, so agreement does not establish performance. Endline use may follow pregnancy, exclusion and monotonicity require additional assumptions, and weak identification or selection into complete follow-up can affect both methods. The pregnancy indicator also has varying follow-up duration rather than a fixed 24-month window.
