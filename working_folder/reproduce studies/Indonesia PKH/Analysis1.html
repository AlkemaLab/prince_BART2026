Indonesia PKH: household heterogeneity without district predictors

Study overview

Estimate the effects of PKH receipt on maternal healthcare using princeBART. This alternative specification excludes district (kabupaten) from both the model and the segmentation tree, allowing segments to reflect baseline household characteristics. It uses the same sample, missing-value handling, and model settings as Analysis.qmd. Removing district adjustment changes the specification; this is an exploratory analysis of household heterogeneity.

Sample and model preparation

Keep the same sample as Analysis.qmd, including its geography availability requirement, then remove kabupaten from the model data. For fitting, missing factor values become a Missing level; missing numeric values are zero-filled with missingness indicators. The loaded dat retains its original NA values.

baseline_controls <- grep("_baseline$", names(dat), value = TRUE)
required <- c("good_assisted_delivery", "delivery_facility", "L07",
              "pkh_by_this_wave", "kabupaten", "kecamatan")
model_dat <- dat[complete.cases(dat[required]), ] |>
  select(-kabupaten) |>
  droplevels()
for (variable in baseline_controls) {
  value <- model_dat[[variable]]
  if (!anyNA(value)) next
  if (is.factor(value)) {
    model_dat[[variable]] <- factor(
      replace(as.character(value), is.na(value), "Missing"),
      levels = c(levels(value), "Missing")
    )
  } else {
    model_dat[[paste0(variable, "_miss")]] <- as.integer(is.na(value))
    model_dat[[variable]][is.na(value)] <- 0
  }
}
baseline_controls <- grep("_baseline(_miss)?$", names(model_dat), value = TRUE)
baseline_controls <- baseline_controls[vapply(model_dat[baseline_controls],
  function(x) n_distinct(x) > 1L, logical(1))]
covariate_rhs <- paste(baseline_controls, collapse = " + ")
settings <- list(n_chains = 4L, workers = 4L, n_warmup = 500L,
                 n_samples = 750L, n_trees = 50L)

The common sample contains 2154 delivery records in 357 subdistricts. Instrument propensity is estimated from the included household predictors. Multiple deliveries from a mother remain; the likelihood does not adjust for subdistrict or mother-level clustering, so credible intervals are not cluster-adjusted.

Estimation and segmentation

Report posterior mean complier effects and 95% credible intervals in percentage points. The segmentation tree chooses household predictors and has at most four leaves, with at least 50 expected compliers per leaf. A single segment is possible if the fitted effects do not support an admissible split.

Code 
analyze_pkh <- function(outcome) {
  old_plan <- plan()
  on.exit(plan(old_plan), add = TRUE)
  if (settings$workers == 1L) plan(sequential) else plan(multisession, workers = settings$workers)
  set.seed(20261102)
  fit_ps <- prince_BART(
    as.formula(paste(outcome, "~", covariate_rhs, "| L07 | pkh_by_this_wave")),
    data = model_dat, uptake_type = "binary", n_chains = settings$n_chains,
    workers = settings$workers, n_warmup = settings$n_warmup,
    n_samples = settings$n_samples, n_trees = settings$n_trees, keep_trees = FALSE
  )
  plan(sequential)
  chains <- lapply(fit_ps$chains, function(chain) {
    pc <- 1 - chain$p_a - chain$p_n
    rowSums(pc * (chain$m_y1c - chain$m_y0c)) / rowSums(pc)
  })
  tau <- unlist(chains, use.names = FALSE)
  estimate <- tibble(
    Estimate_pp = 100 * mean(tau),
    Lower_pp = 100 * unname(quantile(tau, 0.025)),
    Upper_pp = 100 * unname(quantile(tau, 0.975))
  )
  draws <- as_draws_array(array(unlist(chains),
    c(length(chains[[1]]), length(chains), 1),
    dimnames = list(NULL, NULL, "Complier effect")))
  segments <- segment_heterogeneity(
    fit_ps, vars = baseline_controls,
    rpart_control = rpart::rpart.control(cp = 0, maxdepth = 2),
    min_compliers_bucket = 50, ci_level = 0.95, plot = TRUE
  )
  effects <- as_tibble(segments$effects) |>
    transmute(segment, Estimate_pp = 100 * mean,
              Lower_pp = 100 * ci_lower, Upper_pp = 100 * ci_upper,
              n, Expected_compliers = n_group)
  effect_plot <- segments$plot$effect +
    ggplot2::scale_x_continuous(labels = function(x) format(100 * x, trim = TRUE)) +
    ggplot2::labs(x = "Complier effect (percentage points)", y = NULL)
  list(estimate = estimate,
       diagnostics = summarise_draws(draws) |> select(variable, rhat, ess_bulk, ess_tail),
       effects = effects, plot = effect_plot)
}

Positive effects indicate increased use of maternal healthcare among households whose PKH receipt was changed by rollout assignment. n counts delivery records; Expected_compliers sums posterior complier probabilities. Factor levels retain the authors’ category indices; Missing and _miss splits describe data availability. Household segments can also reflect geographic differences because household characteristics and location may be correlated. These post hoc summaries do not establish subgroup differences or account for selection of the tree.
